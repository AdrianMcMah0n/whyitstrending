Privacy Policy

Why It's Trending. Last updated 20 September 2026.

This policy covers the private application used by the owner of the Why It's Trending YouTube channel to publish videos to that channel. The application is personal tooling. It is not distributed to other people, has no other users, and has no sign-up.

What the application accesses

When the channel owner signs in with their own Google account, the application requests these Google API scopes:

  • youtube.upload - to upload finished video files to the owner's own YouTube channel.
  • youtube.readonly - to read the name and ID of the owner's own channel, so the application can confirm it is about to upload to the correct channel before it does so.

These scopes are used for those two purposes only. The application does not read, modify or delete any other content in the account.

What is stored, and where

The Google authorisation token is stored in a single file on the channel owner's own computer. It is not transmitted anywhere else, not stored on any server, and not shared with anyone. It can be revoked at any time from the Google account permissions page, which immediately ends the application's access.

What is not collected

  • No data is collected from visitors to this website.
  • No analytics, advertising or tracking technologies are used on this site.
  • No personal data is collected from anyone other than the channel owner.
  • No data is sold, rented or shared with third parties for any purpose.

Video content

Videos published to the channel summarise reporting that has already been published by news outlets. Each video credits the outlets it drew on. No personal information about viewers is used to produce any video.

Limited use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the revised version will be posted on this page with an updated date.

Contact
